# X11 desktop adapter

`X11::open` owns a checked XCB connection and caches the atoms used for focus. `property` reads bounded replies, and `focus` resolves the active window's application ID and class. A stale or removed window produces no match. `Reply` frees XCB's allocated replies.

`Paste::open` loads the known XTEST runtime library and verifies the extension. `focus` records the current X11 input target. `paste` checks that target and modifier state before sending Ctrl+V and preserves a physically held Ctrl key. Drop closes the X11 display and runtime handle. Neither adapter modifies desktop settings.

`test_focus` publishes foreground properties for the disposable Xvfb test window. The smoke test checks those properties, rejects a changed target, and pastes Unicode into a local GTK editor.

`property_size` checks the declared element count against the actual wire payload length and read maximum before XCB memory is exposed as a slice.
