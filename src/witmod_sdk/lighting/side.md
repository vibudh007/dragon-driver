# Side-light preview

Direct preview constructors clamp their cell counts to the DLL's 60-slot array. `SidePreview::steady(cell_count, color, clear_color)` creates the constant or off display. `breathing(cell_count, foreground, background, rainbow)` creates the mode 1 preview. `cells()` borrows the mode's current LED values. `tick()` runs one step. Unlike the keyboard mode, the side routine continues processing every cell on the frame that enters the fade pause.

The corresponding initialization and run routines are `0x1000dd10` and `0x1000de80`. Modes 0 and 5 use `0x1000eaf0` and `0x1000e040`. `pulse(cell_count, color, rainbow)` creates mode 4. Its brightness pause advances per cell through the same routine used by the keyboard pulse. Rainbow begins at red and advances along RGB edges. Initialization and tick are at `0x1000e7e0` and `0x1000e8a0`. `wave_default` creates the default mode 2 setup. It starts at zero brightness for mono, and at black with full intensity for rainbow. The shared wave update comes from `0x100103b0`. `wave_for_model` selects the [named layout tables](side/geometry.md) in `0x1000eb80`. [Collision](side/collision.md) documents mode 3 and its configuration bytes. The Rust preview stores its cells in a vector.
