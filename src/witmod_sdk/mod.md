# Witmod SDK module

- [Discovery](discovery.md), [catalog](catalog.md), [session](session.md), and [identity](identity.md) identify the configuration interface and read device metadata.
- [Report framing](hid.md) and the [Linux HIDRAW transport](hidraw.md) handle packet conversion and device I/O.
- [Profiles](profile.md), [macro encoding](macros.md), and [key tables](keymap.md) implement persistent configuration and keyboard mappings.
- [Keyboard preview](lighting.md), [side preview](lighting/side.md), and [timing](timer.md) hold preview state and advance frames.
- The port overview and export coverage track scope and evidence.
