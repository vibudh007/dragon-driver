# Live receiver lighting

`Live::new` validates the selected preset and creates only the SDK preview engines needed to render its receiver telemetry. `item` adapts the live report settings to the preview types. Auto effects that render on the receiver use the selector alone. `press` maps a local USB usage to the vendor key matrix and stages a single event. `packet` sends RGB colors, one-shot reactive events, row intensity, or the automatic ripple latch as appropriate. `side_frame` includes the supported side RGB, wave, or collision fields. `audio_packet` writes the two eleven-band arrays while preserving the side region. Vendor receiver path

The renderer and wire framing are exercised offline. Receiver-specific visual timing, the audio peak decay approximation, and the Linux event permissions still require hardware verification.
