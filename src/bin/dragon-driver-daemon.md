# Dragon Driver daemon

The binary has two roles. The authorized systemd instance runs as root and receives its listener from the system manager. It checks the configured user's peer credentials and accepts only requests to open supported configuration HID interfaces. An exclusive lease follows the descriptor through the desktop daemon to the CLI. The system instance never reads palettes, records audio, or executes files from a user's workspace.

The desktop instance runs as the logged-in user. It relays permitted keyboard descriptor requests to the system instance, owns the RON file, and serves read-only snapshots to clients. RON writes are serialized across at most eight client handlers. The idle effect observer borrows a keyboard only when the CLI has released it. With the GUI connected, the GUI's ordinary reads submit observed effect changes to the desktop daemon.

`Recorder::open` starts native PipeWire capture with `pw-record` and an untargeted sink-monitor stream. The session manager attaches it to the default output. The child requests 10 ms latency and emits 44.1 kHz mono PCM. `capture` runs the rolling spectrum for Audio-reactive lighting and sends only 22 bar heights per frame. The legacy CLI microphone-free desktop stream still receives PCM on its existing operation. One client owns the recorder. `relay_audio` stops on socket disconnect and dropping the recorder reaps the child. The daemon writes no audio to disk. [PipeWire stream properties](https://docs.pipewire.org/page_man_pipewire-props_7.html) · [WirePlumber default routing](https://pipewire.pages.freedesktop.org/wireplumber/daemon/configuration/settings.html)

The desktop instance owns both reactive lighting renderers, including wallpaper subscriptions, image processing, PipeWire capture and live RGB writes. Its effect state survives the frontend. The CLI transport and renderer coordinate access through a shared lease and a configuration lock. [Reactive lighting](../reactive.md) The root broker has no wallpaper operation. [Wallpaper discovery](../wallpaper_source.md)

Managed mode monitors the AppImage or executable path and Flatpak registration. When all registered frontends are absent for 30 seconds, it retires that UID's system access socket and removes its desktop registration and units. The root broker accepts retirement only for its own authenticated UID. The shared unit templates and RON data stay available for later installs. [Host setup](../../packaging/setup-desktop-service.md)

`Restored::once` tracks the verified interface for each device node. The background observer and first broker lease share this tracker. Both restore persisted per-key pages and effects before the device is exposed for configuration or used by a reactive renderer. The observer forgets disconnected interfaces and records later effect changes. `Reactive::resume` loads the saved selection at startup and starts it after restoration. [Saved lighting](../palettes.md)
